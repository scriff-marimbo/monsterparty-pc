# Names for the JP prototype disassembly only (monsterparty_jp/). Same format as tools/names.txt:
#   $ADDR Name [size] ; comment        RAM
#   label Old New ; comment            rename a label
#   at bankN $ADDR Name ; comment      new label (JP addresses)
# Apply: python3 tools/apply_names.py monsterparty_jp tools/jp/names_jp.txt && ./monsterparty_jp/build.sh
#
# Most labels came from the US names, so a rename in tools/names.txt does NOT reach monsterparty_jp/.
# Add it here too if you want it in both.
#
# ---- bosses: by default the JP labels keep the US boss names (see tools/jp/bosses.md for the
# prototype names). To give a JP label its prototype name instead, uncomment and edit, e.g.:
# label b5_Boss03_PumpkinGhost b5_Boss03_JPName ; JP prototype name (US: Pumpkin Ghost)
